# 授权判定与缓存无关，不按读取回源校验

仓库凭证由管理员在服务端配置，客户端不携带上游身份，所以"缓存读取须与上游同等校验"定义为：每次请求都按当前配置做同一套授权判定（允许列表 × 令牌范围 × 存在匹配凭证或公开仓库），判定先于缓存查找、不看数据是否已缓存；配置收紧立即生效。我们**不**在每次读取时回源（如 `ls-remote`）校验服务端凭证是否仍有效，因为那会抵消缓存的延迟优势；代价是上游撤销凭证的传播延迟以分支 TTL 为上限——下次刷新 fetch 失败后该仓库被标记为凭证失效并拒绝读取。

## Considered Options

- 身份透传（客户端带自己的上游身份）：与"服务端集中配置凭证"冲突，排除。
- 命中缓存时按 TTL 回源校验：更严，但每次检索多一次网络往返，v1 不采用。
